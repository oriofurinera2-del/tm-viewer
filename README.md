# TM Viewer

TOKYO Motion を PC で快適に見るための、Windows 専用の閲覧アプリです。
フレンド・購読ユーザーの新着動画をまとめて見る機能を中心に、閲覧まわりの不便を解消します。

配布版は [GitHub Releases](https://github.com/oriofurinera2-del/tm-viewer/releases) から入手します。このリポジトリではアプリのコードを確認できます。

- 本人と知り合い向けのアプリです。すべての処理は各自の PC 内で完結し、外部サーバーには送信しません。
- 現在 **開発中（v0.1）** です。一部の機能はまだ作成中です。

---

## できること

### 見る・集める
- **新着フィード**：フレンド＋購読ユーザーの新着動画を 1 か所にまとめて表示（公式サイトに無い機能）
- **見られる動画だけ切替**：PRIVATE を隠す／フレンドの PRIVATE は表示
- **NEW・視聴済みマーク**：前回開いた以降の新着を強調し、見た動画は薄く表示
- **新しい順に並べる**：動画 ID を基準に並べ、「◯◯頃」の推定投稿日も表示
- **個人の全動画**：人を選ぶと、その人の動画を 100 件ずつ遡って表示
- **サイトのタグ表示・絞り込み**
- **サムネのホバー切り替え**：カードにカーソルを当てると 2 枚目以降を順に表示

### 整理する（保存はすべて自分の PC 内だけ）
- **独自の名前・独自タグ・★（1〜5）** を動画ごとに付ける
- **整理した動画**：付けた動画を絞り込み・並べ替えして一覧表示
- **書き出し／読み込み（JSON）**：PC の入れ替え・故障に備える

### 操作する
- **アプリ内検索（開発中）**：サイト検索に語を渡し、結果をアプリのカードで表示する予定
- **ダウンロード**：自分で再生できる動画を保存（HD 優先）。進捗・失敗・やり直しを一覧で管理
- **サイト表示（簡易ブラウザ）**：ログイン・再生・新着閲覧・フレンド申請などを自分で操作

### 安全・負荷対策
- **許可リスト方式の広告遮断**：許可したドメイン以外の通信・ポップアップ・外部への移動を止める
- **サイトへの負荷を抑える**：1 件ずつ・間隔あり・キャッシュあり・手動更新が基本
- **ログイン情報の保存は任意（初期値オフ）**：オンにした場合のみ暗号化して保存

やらないこと：外部サーバーの利用、ID・パスワードの勝手な読み取り、投稿・コメント・フレンド申請などの書き込み操作の自動化。

## 使い方

### 最初の 1 回だけ
1. **exe を起動します。** 未署名のため、初回は Windows の SmartScreen 警告が出ます。
   「詳細情報」→「実行」で起動できます（安全のため、配布元の Releases 以外からは入手しないでください）。
2. **サイト表示タブ**にサイトのログイン画面が出ます。**自分で ID・パスワードを入力**してログインします。
3. （任意）毎回ログインし直すのが面倒なら、**設定タブ**で「ログイン情報を保存して自動でログインする」をオンにします。
   ※自分専用の PC で、他で使い回していないパスワードのときだけにしてください。

### 普段の使い方
1. **フィードタブ**を開きます。起動時に 1 回だけ自動で更新し、前回分をすぐ表示しながら裏で新着を取りに行きます。
2. 手動で更新したいときは上の **「更新」ボタン**を押します。
3. **左の一覧で人を選ぶ**と、その人だけに絞れます。「すべて」で全員分。見たくない人は**目のアイコンで非表示**にできます。
4. **カードをクリック**するとサイト表示タブで再生します（開いた動画は視聴済みになります）。
5. 気になる動画は **★を直接クリック**、**✎で名前・独自タグ**を付けられます。
6. 保存したい動画は **ダウンロードボタン**を押すと、ダウンロードタブで進み具合を確認できます。

### 探す・整理する
- **検索**：アプリ内検索は開発中です。現在はサイト表示から検索できます。
- **整理した動画**：★や名前を付けた動画をまとめて表示。絞り込み・並べ替えができます。
- **設定**：取得間隔・キャッシュ時間・ログアウト・履歴消去・データの書き出し／読み込み。

### コツ
- 更新は**手動が基本**です（サイトに負担をかけないため）。放っておいても勝手に何度も取りに行きません。
- タグは 2 種類あります：**サイトのタグ（読むだけ）** と **自分の独自タグ（自由に付け外し）**。どちらでも絞り込めます。

## 開発者向け

```bash
npm install
npm start        # アプリを起動
npm test         # テスト
npm run dist     # Windows x64 向け portable exe を dist/ に作成
```

配布版には `src/`、`data/allowlist.json`、実行に必要な依存パッケージのみを含めます。開発用の文書・テスト・AI 向け設定は含めません。

設計は [docs/DESIGN.md](docs/DESIGN.md) を正とします。
